## Lessons recorded (also in memory)

- Degrade maps only after rotation and pixel averaging; never degrade RM.
- croissant picks the dense engine for lmax < 2·nside and lmax is capped at
  2·nside; batch at nside 64 instead.
- Kelvin: push a uniform 1 K sky through the same pipeline; the branch's
  records use the same 1 K enclosure reference.
- Remove the per-parent smooth fit before a delay transform; down-weight the
  aliased edge zoom bins (30–44 % folded response for the outermost bins).
- A single pixel's factor is not monotonic in sub-pixel roughness; the
  ensemble rms is.
- Ensemble draws must go through the same channel operator as the map.
